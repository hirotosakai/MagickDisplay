# MagickDisplay

## 概要

MagickDisplayは、macOS用のシンプルな画像ビューアです。
ImageMagickを活用することで、多くのファイル形式に対応します。
また、Quick Look機能拡張も含んでいます。
ソースコードのほとんどは、生成AIを利用して作成しています。

## アプリ

### 基本機能

- 画像ファイルを開くと、ウインドウサイズを画像の大きさに合わせて表示します。
  （デスクトップからはみ出ないよう調整します）
- ウインドウをリサイズすると、画像は縦横比を維持したまま拡大/縮小されます。
- メモリ使用量や表示速度を最適化するため、メインディスプレイの縦横いずれか
  長い方を超える画像は、ImageMagickの機能で超えないようリサイズします。
- ImageMagickが対応していない形式のファイルを開こうとした場合、
  エラーダイアログが表示され、ウインドウは開きません。

### メニュー

- 「表示＞左(右)へ回転」を選択すると、画像を左(右)へ90度回転します。
  ウインドウは画像の大きさに合わせてリサイズされます。
  （デスクトップからはみ出ないよう調整します）
- 「表示＞実際のサイズ」を選択すると、画像の大きさに合わせて
  ウインドウをリサイズします。（デスクトップからはみ出ないよう調整します）
- 「プリント...」を選択すると、表示している画像を印刷します。
  また「ページ設定...」を選択すると、用紙サイズ他を設定できます。

## Quick Look機能拡張

- macOS標準のクイックルックでプレビューが表示される形式では
  発動しないようにしています。（発動する形式は `Documents/uti.md` を参照）
- 縦横それぞれ800pxを超えない大きさにリサイズして表示します。

## ビルド

MagickDisplayをビルドするには、Xcodeでビルド、またはターミナルで
`xcodebuild`を実行します。

MagickDisplayをビルドする前に、ImageMagick (version 7)をビルドし、
`libMagick{Core,Wand}-7.Q8.dylib`をプロジェクトルートに置く必要があります。
optディレクトリにスクリプトを置いています。必要に応じてご利用ください。
1. `BuildTools.sh`  - 画像ライブラリのビルドに必要なツールをビルド
2. `BuildLibs.sh`   - ImageMagickにリンクさせる画像ライブラリをビルド
3. `BuildMagick.sh` - ImageMagickをビルド
